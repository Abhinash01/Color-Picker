# 🎨 Color Picker

A mini UI + logic project that lets users pick a color and dynamically changes the background color while displaying the selected hex code.

## 🚀 Features

- Real-time background color change using a color input
- Displays selected color code
- Smooth transitions with CSS
- Clean, minimal interface

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript



## 📂 How to Use

1. Clone this repository:
git clone https://github.com/YourUsername/Color-Picker.git

2. Open `index.html` in your browser.

## 📚 Concepts Practiced

- `input[type="color"]` event handling
- DOM manipulation with JavaScript
- Updating UI dynamically with user input
- CSS transitions for smooth effect

- JavaScript beginners
